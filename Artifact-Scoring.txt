# Artifact scoring model

The scoring model evaluates each artifact on a 0 to 100 point scale divided across four operational dimensions, followed by a hard security gatekeeper.
All formulas map directly to the exact JSON keys present in http_sources and playwright_sources.

Score Breakdown (100 Points Total)
+-----------------------------------------------------------------------+
|  Dimension 1: Ecosystem Adoption (35 pts)                             |
|  - deps_dev.dependentCount (15 pts)                                   |
|  - libraries_io.dependentRepositoriesCount (12 pts)                   |
|  - deps_dev.starsCount (8 pts)                                        |
+-----------------------------------------------------------------------+
|  Dimension 2: Freshness & Velocity (25 pts)                           |
|  - search_maven_org.timestamp / repo1_maven_org.lastUpdated (15 pts)   |
|  - search_maven_org.versionCount (10 pts)                             |
+-----------------------------------------------------------------------+
|  Dimension 3: Security & Hygiene (25 pts)                             |
|  - osv_dev.vulns active severity penalty (15 pts)                     |
|  - deps_dev.scorecard.overallScore OR libraries_io.sourceRank (10 pts)|
+-----------------------------------------------------------------------+
|  Dimension 4: Packaging & IDE Usability (15 pts)                      |
|  - search_maven_org.ec (Presence of .jar, -sources, -javadoc) (15 pts)|
+-----------------------------------------------------------------------+
